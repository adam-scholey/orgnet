# ── System Prerequisites ─────────────────────────────────────────────────────

# Runtime / SDK
.NET 10 SDK                             # https://dotnet.microsoft.com/download/dotnet/10.0
Windows 10 (Build 19041) or later       # Required for WinUI 3 desktop client
Windows App SDK 1.x                     # Bundled via NuGet, but Windows 10+ required

# Database
PostgreSQL 16+                          # Primary data store (row-level multi-tenancy)
Redis 7+                                # Optional — real-time event bus & caching

# Containerisation (optional)
Docker Desktop                          # For docker-compose based setup
Docker Compose v2                       # Orchestrates PostgreSQL + Redis + API

# Build Tools (optional, for load testing)
k6                                      # https://k6.io — for performance/load tests
